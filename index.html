Beacon Worship & Media

What is new
NEW IN 1.1.0: TWO COMPUTERS, SAFELY - Beacon Worship & Media can now be used on two computers (for example the Music Leader's laptop and the pastor's computer). Online & Sharing → 5: import the Google sign-in file (the same one as Beacon Admin's; on a computer with Beacon Admin it offers that one), click Connect, then Sync Now. The songs, set lists, devotionals and teams then go between the computers through the church's Google Drive (at start, every 10 minutes, before Publish and when closing); when both changed something, the two are combined and nothing is lost. Only ONE open computer at a time does the changes from the Music Leaders' phones and the automatic publish, so nothing is done twice; the other one says which computer does it, and takes over by itself 10 minutes after that one is closed (or at once with "Do the phones' changes on this computer"). A new computer can choose "From the other computer, through Google Drive" at the first start. Also: when the church's website needs a newer Beacon Worship & Media, this program says "Please update" and stops going online until it is updated (so an old copy cannot undo the new one's work); it can sign in with a Beacon Worship & Media account (worship_office) that can do only the worship and media work, not everything of the office. Needs Website Update 106 (rules 57) for the last three; with older rules it works as 1.0 did.

How to install or update

  1. Click Download for Windows on the program you need.
  2. Open the downloaded .zip file: right-click it → Extract All.
  3. Double-click the Setup file inside, then Yes, Next and Install.
  4. Already installed? Run the new setup the same way. It updates the program and keeps the church records.
If Windows says “Windows protected your PC”, click More info, then Run anyway. It appears because these programs are made by the church, not by a large company.
The programs are for the church's officers. Opening the church's records still needs the church's sign-in; a new computer starts empty until it is connected to the church's records.

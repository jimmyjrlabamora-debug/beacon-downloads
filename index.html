Beacon Finance

Giving, expenses, funds and the monthly reports. For the treasurer and the finance team.

Version 48.21.026 November 202625 MB
Download for Windows
What is new
48.21.0 (November 2026) THE PASTOR'S ROLES WAIT FOR YOUR OK; SECURITY RULES 57

- Who handles the church's money (Disbursing Officers, Treasurers, Approvers, Auditors) is no longer changed by itself when the pastor changes the Roles on the phone. Beacon Finance asks once ("Accept this change now?"), and Portal Finance Roles shows the waiting change with Accept the pastor's change. Until it is accepted, everything stays as it was here (the pastor's page on the phone shows what Beacon Finance still has). So a change made on a phone alone can never give anyone the right to approve or release money.

- When the church's website needs a newer Beacon Finance (Beacon Pastor → Publish Everything says so), this program says "Please update" and sends nothing to the portal until it is updated; reading still works.

- Online Giving → Copy Security Rules / Make Giving Page Files give rules version 57 (Website Update 106).

How to install or update

  1. Click Download for Windows on the program you need.
  2. Open the downloaded .zip file: right-click it → Extract All.
  3. Double-click the Setup file inside, then Yes, Next and Install.
  4. Already installed? Run the new setup the same way. It updates the program and keeps the church records.
If Windows says “Windows protected your PC”, click More info, then Run anyway. It appears because these programs are made by the church, not by a large company.
The programs are for the church's officers. Opening the church's records still needs the church's sign-in; a new computer starts empty until it is connected to the church's records.

# Beacon Downloads

The latest Windows setups of Beacon Christian Assembly's church programs (Beacon Finance, Secretary, Attendance, Admin, Cam Host).

**Download page:** see the link in this repository's About box (GitHub Pages).

This repository is filled automatically: when a new version is made, GitHub builds its setup in the church's private
`beacon-apps` repository and copies it here (Releases), then updates the page (Beacon Cam Host's setup comes from its own
private repository, `beacon-cam-host`). Nothing here is edited by hand.
